# NNNN — Title as a short statement of the decision

- **Status:** Proposed | Accepted | Superseded by NNNN | Deprecated
- **Date:** YYYY-MM-DD
- **Decided by:** name (area owner from OWNERS.json)
- **Area:** accounting / billing / customer / infra / shared

## Context

What forced a decision. The facts, with links to the evidence (commit, migration, incident,
measurement). Two or three short paragraphs.

## Decision

What we do, stated so that someone could check whether the code follows it.

## Consequences

- What gets easier.
- What gets harder, or what we give up.
- What must stay true for this to keep working (and which test or check proves it).

## Alternatives considered

- Option — why not, in one line.
