# New client project — template

Copy this folder into the root of a new client repo as `docs/` (and `CLAUDE.md` to the repo root) on day one. The AI fills the files; people only do the steps marked 👤.

| File | Filled by | When |
|---|---|---|
| `CLAUDE.md` (copy to repo root) | — | Day one; tells the client project's AI how to work |
| `REQUIREMENTS.md` | AI, from Pawan's meeting notes | Step 1, updated at every demo |
| `ESTIMATE.md` | AI draft → 👤 Pardeep (scope) + 👤 Hitesh (price) | Step 2 |
| `MILESTONES.md` | AI (dates, what is in each) → 👤 Hitesh (invoice per milestone) | Step 2, ticked as they finish |
| `PROGRESS.md` | AI, one short entry per working day | Step 3 onwards (also sent to the client) |
| `HANDOVER.md` | AI draft → 👤 Abhishek (logins, training) | Step 6 |

The seven steps and who does what: `docs/TEAM-PROTOCOL.md` → "Team model" in the ResellerOS repo.
