# Role routines — one daily checklist per person

Each person sets this up ONCE in their own Claude app (Code tab → Scheduled → New task), pasting the text from their file. It runs while the app is open. It only reads the board and their notes, drafts things for them, and tells them their own steps — it never logs in, never sends anything to a client, never deploys.
