## Three things I got wrong today, so they don't get re-learned

1. **Removed `include_granted_scopes` from the Gmail flow** reasoning the scopes column should
   record only what was asked. Backwards — both flows write the same `user_google_tokens` row,
   so it would have stored a send-only token and **broken contacts sync**. Caught before shipping.
2. **Set the leads sticky header to `top-0`**, which reintroduced the exact TopBar collision
   reported earlier. Both causes had to be fixed together.
3. **Measured layout at an unknown scroll position** and drew a confident wrong conclusion —
   twice. The fix: `scrollTo(0,0)`, measure, scroll, measure again, and check `h1` to confirm
   you're on the page you think you are.
